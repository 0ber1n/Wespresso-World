WESPRESSO WORLD — CTFd LAB SETUP
=================================

WHAT WAS ADDED
--------------
docker-compose.yml      Updated to include CTFd, MariaDB, and Redis services
                        on a shared Docker network called "lab"

ctfd/challenges.yaml    Six pre-written challenges mapped to real vulnerabilities
                        in the Wespresso World app

ctfd/package.sh         Script that packages challenges.yaml into a
                        CTFd-importable zip file

SERVICE MAP
-----------
Wespresso World frontend    http://localhost:31337
Wespresso World API         http://localhost:1337/api/v1
CTFd platform               http://localhost:8000
MariaDB                     internal only (ctfd-db:3306)
Redis                       internal only (ctfd-redis:6379)


FIRST-TIME SETUP
----------------

1. CONFIGURE SECRETS (optional but recommended)
   Add these to your .env file before starting:

       CTFD_SECRET_KEY=your-random-secret-here
       CTFD_DB_PASS=your-db-password-here
       CTFD_DB_ROOT_PASS=your-root-db-password-here

   If you skip this, the compose file uses default values which are
   fine for a local offline lab but should not be exposed publicly.

2. START THE STACK
   From the project root:

       docker compose up -d

   CTFd will wait for MariaDB to pass its health check before starting.
   First boot takes 30-60 seconds. Watch progress with:

       docker compose logs -f ctfd

3. COMPLETE CTFd FIRST-RUN WIZARD
   Open http://localhost:8000 in your browser.
   You will be prompted to:
     - Set a CTF name (e.g. "Wespresso World CTF")
     - Create an admin account (remember these credentials)
     - Choose CTF mode (individual recommended for a lab)
     - Set start/end times (leave blank for always-open)

4. IMPORT THE CHALLENGES
   a. Run the packaging script from the project root:

          ./ctfd/package.sh

      This creates wespresso-challenges.zip in the project root.

   b. In CTFd: Admin Panel (top right) → Import → select wespresso-challenges.zip

   c. Click Import. All six challenges will appear under Challenges.

5. UPDATE THE TARGET IP IN CHALLENGE DESCRIPTIONS
   The challenges reference "<host>" as a placeholder.
   Go to Admin Panel → Challenges → edit each challenge and replace
   <host> with your actual machine IP or hostname.

   If running everything locally:       localhost  or  127.0.0.1
   If players are on a different machine:  your LAN IP (e.g. 192.168.x.x)

6. SET YOUR FLAGS (optional — defaults are already set)
   Default flags are set in challenges.yaml. If you want custom flags,
   edit them in CTFd: Admin Panel → Challenges → select a challenge → Flags.

   Note: "The Decaf Protest" flag depends on the actual cart math.
   The default flag is flag{-1.00} (adding qty -1 of a $1.00 item).
   Test it yourself and adjust if the seeded drink prices differ.

STOPPING AND RESETTING
-----------------------
Stop all services:
    docker compose down

Stop and wipe ALL data (CTFd DB, uploads, Redis cache):
    docker compose down -v

Restart just CTFd:
    docker compose restart ctfd


TROUBLESHOOTING
---------------
CTFd won't start
    Check DB health:  docker compose logs ctfd-db
    CTFd needs MariaDB to be fully ready. Wait 60s and retry:
        docker compose restart ctfd

Port 8000 already in use
    Change the CTFd port in docker-compose.yml:
        ports:
          - "9000:8000"    # change 9000 to whatever you want

Lost CTFd admin password
    docker compose exec ctfd flask shell
    >>> from CTFd.models import Users
    >>> u = Users.query.filter_by(type='admin').first()
    >>> u.password = 'newpassword'    # CTFd will hash it on save
    >>> from CTFd import db
    >>> db.session.commit()
